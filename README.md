# Facture LBC

Application web (HTML/CSS/JS) pour générer des attestations/factures de vente à partir d'une confirmation de vente Leboncoin ou en saisie manuelle.

## Fonctionnalités
- Coller une confirmation de vente Leboncoin pour extraire automatiquement les informations.
- Remplir manuellement les champs.
- Générer une attestation de vente imprimable (PDF via impression navigateur).

## Utilisation
Ouvrir `index.html` dans un navigateur, ou activer GitHub Pages sur la branche `main`.
